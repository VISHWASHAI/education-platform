# education-platform

EduFlow — a full-stack school management platform built for People's Education Society.

- `frontend/` — React + Vite + Tailwind SPA
- `backend/` — Express + PostgreSQL API (local development)
- `supabase/` — Postgres migrations + a Supabase Edge Function (Hono/Deno) port of the
  backend, used for production deployment (Vercel frontend + Supabase backend)

See [DEPLOYMENT.md](DEPLOYMENT.md) for the full deploy walkthrough.
